# forwardprop.github.io

보안 사건 분석·취약점 연구·로봇(ROS 2) 보안 공부 기록 — https://forwardprop.github.io

- [Jekyll](https://jekyllrb.com) + [Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy) 테마(chirpy-starter 기반, 해당 코드는 `LICENSE`의 MIT 라이선스)
- `main`에 push하면 GitHub Actions가 빌드·배포
- 글(`_posts/`, `_drafts/`)의 저작권은 작성자에게 있음

```bash
bundle install
bundle exec jekyll serve --drafts   # http://127.0.0.1:4000
```
